# First-Person Shooter Project — Unreal Engine 5

An Unreal Engine 5 FPS prototype focused on gameplay programming, combat systems, enemy AI, objectives, and HUD/UI systems.

**Status:** In Progress

## Overview

This project is being developed while learning Unreal Engine 5 and following the concepts from the Coursera course **Unreal FPS Development – Combat AI and UI Systems**.

The project has grown into a playable FPS prototype with weapon systems, player health and armor, enemy AI, objectives, minimap, timer, kill feed, and custom HUD elements.

## Features

### Weapons & Combat
- AK-47 weapon system
- M4A1 weapon system
- Primary/secondary weapon switching
- Weapon visibility switching
- Projectile-based firing
- Reload animation
- Ammo pickup with sound
- Muzzle flash setup
- Hit effects
- Hit marker
- Dynamic crosshair

### Player Systems
- Health system
- Armor system
- Health and armor HUD
- Damage handling
- Damage effects
- Damage/pain volume
- Repeated damage while inside the damage volume
- Health regeneration after leaving the damage volume

### Enemy AI
- Basic enemy AI
- Enemy follows the player
- Enemy reacts to bullet hits
- Enemy hit effects
- Enemy scouting within a defined radius
- Basic combat behavior

### Objectives
- Multiple objective points
- Objective IDs
- Dynamic objective names
- Objective progression
- Objective HUD updates
- Objective completion flow

### HUD & UI
- Health bar
- Armor bar
- Health and armor values
- Dynamic crosshair
- Kill feed
- Timer
- Live minimap
- Minimap player arrow
- Ammo display
- Weapon icons
- Grenade icons
- Objective display
- Hit marker
- Custom sci-fi HUD design

### Minimap
- Scene Capture Component 2D
- Minimap render target
- Custom minimap material
- Player direction indicator
- Custom minimap border
